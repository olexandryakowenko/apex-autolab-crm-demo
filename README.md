# APEX AutoLab · CRM Demo

Інтерактивний демопрототип CRM для автосервісу. Це статичний фронтенд: кнопки й демонстраційні сценарії працюють у браузері, демодані зберігаються локально на пристрої. Інтеграції з реальними камерами, обліковими системами чи сервером тут немає.

## Перегляд онлайн

Щоб опублікувати сайт, відкрий **Settings → Pages**. У розділі **Build and deployment** вибери **Deploy from a branch**, branch `main`, папку `/ (root)`, потім натисни **Save**. Публікація може тривати кілька хвилин.

Після ввімкнення Pages адреса буде: https://olexandryakowenko.github.io/apex-autolab-crm-demo/

## Відкрити на телефоні

На iPhone відкрий посилання у Safari, натисни **Поділитися → На початковий екран**. На Android відкрий у Chrome й вибери **⋮ → Встановити застосунок** або **Додати на головний екран**.

## Демодані

Публічна копія використовує псевдонім **Alex Apex**, нейтральні демонстраційні імена й адреси, а також умовні номери автомобілів. Не вводь реальні персональні або клієнтські дані в публічному демо.
